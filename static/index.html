Rolling change summary

Analyze tickers to see their latest rolling changes and historical percentiles.

Rolling change compares each close with the last available close on or before the calendar lookback date. Percentage = (price / prior price − 1) × 100; absolute = price − prior price. Insufficient history, unavailable closes and zero percentage bases appear as gaps. All displays the history available within the data service request limit.
